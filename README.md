# Ascreen — главная V3

Вёрстка главной страницы по раскадровке «дизайн-концепт 2» из Figma.

- `index.html` — разметка, стили и скрипты в одном файле
- `img/` — фото кейсов и услуг, логотипы клиентов, иллюстрация
- `media/` — видео первого экрана и постер

Зависимости: шрифты Inter и Oranienbaum (Google Fonts, Oranienbaum — замена TT Ricks), Lenis 1.1.13 для инерционного скролла (jsDelivr).

Если подключить TT Ricks через `@font-face` с именем семейства `TT Ricks`, он подхватится автоматически.

Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
